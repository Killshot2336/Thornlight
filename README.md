# Thornlight — for Kyria

## Setup
1. Run schema.sql in Supabase SQL editor.
2. Upload all files to a GitHub repo.
3. Settings → Pages → main → /root → Save.
4. Open the link on your phone and hers. Add to home screen.

## Author mode
Tap "welcome" 5 times → PIN 2336.
Wrong PIN flashes "welcome aden" and she stays put.

## Publish
Author → Library → + new book → title, tags, paste → publish.
